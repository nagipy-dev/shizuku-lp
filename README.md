# しずく プログラミング教室 LP（HTML / CSS / JavaScript）

架空のプログラミング教室の、1ページ完結のランディングページ（LP）です。

フレームワークを使わず、HTML・CSS・少量の JavaScript だけで作っています。サーバーがなくても動くので、そのまま公開・納品できます。

> このサイトはポートフォリオ用の見本です。教室は実在しません。

## ページ構成

| セクション | 内容 |
|---|---|
| ファーストビュー | キャッチコピー、無料体験への導線、教室の基本情報 |
| 01 教室について | 教室の特徴を3つ |
| 02 コース | 3コースの内容と期間 |
| 03 料金 | 入会金・月謝・教材費の表 |
| 04 受講の流れ | 申し込みから受講開始までの4ステップ |
| 05 よくある質問 | タップで開閉する質問と回答 |
| 06 無料体験の申し込み | 入力チェック付きのフォーム（見本のため送信はしません） |

## 工夫した点

- **余白と線だけで整理したデザイン**：装飾を最小限にし、見出し・余白・細い線で情報を区切っています。色は文字色とアクセントの深い青緑だけです
- **スマートフォン対応**：幅768px以下で1列のレイアウトに切り替わり、メニューは開閉式になります。見出しの文字サイズは画面幅に合わせて変わり、変な位置で改行されないよう調整しています
- **フォームの入力チェック**：未入力や形式の誤りを欄ごとに表示し、入力し直すとすぐにエラーが消えます。最初のエラー欄に自動でカーソルが移動します
- **JavaScript なしでも使える部分は HTML で**：よくある質問の開閉は `<details>` 要素で作っているので、JavaScript が動かない環境でも開閉できます
- **アクセシビリティへの配慮**：メニューボタンに開閉状態（`aria-expanded`）を持たせ、キーボード操作時のフォーカス表示、動きを減らす設定（`prefers-reduced-motion`）にも対応しています
- **修正しやすい CSS**：色・文字・余白を CSS 変数にまとめているので、配色の変更は冒頭の数行を書き換えるだけで済みます

## ファイル構成

```
index.html   ページ本体
style.css    見た目（スマートフォン対応を含む）
script.js    メニューの開閉、ヘッダーの下線、フォームの入力チェック
```

## 確認方法

`index.html` をブラウザで開くだけで表示できます。

ローカルサーバーで確認する場合:

```bash
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。
